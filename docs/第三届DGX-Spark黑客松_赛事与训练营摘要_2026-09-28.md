## 一、先看结论

第三届赛题是 **Agent Skills 开发挑战赛**。公开活动说明强调：用 DGX Spark 的本地算力构建可运行的 Agent 应用，把专业知识、工具调用与标准工作流封装成可复用的 Skill，使 Agent 能实际执行任务和交付结果。[活动主页](https://scrm.nvidia.cn/lp/dgx-spark-hackathon-agent-skills-20260920)；[NVIDIA 中国官方微博发布内容](https://weibo.com/2/detail/5339493013389852)。

这次训练营的三条技术线分别是：**Skill 与 Harness 的可复用封装**、**Skill 的安全和可信治理**、**DGX Spark 上的本地视觉 Agent 实作**。这来自三份讲义公开预览，不等于完整视频的逐段总结。

## 三、三份 PPT 的摘要（仅公开预览页）

### 1. NVIDIA Skills 开发实战：基于 DGX Spark 构建高性能行业 Agent 应用

讲义前 3 页指出，Agent 能力正从模型内置能力转向可安装的外部能力。这里的 Skill 是由 `SKILL.md`、参考资料和脚本组成、可分发的指令包；开放模型、MCP 工具连接和可移植 Skill 共同扩展 Agent 的工作范围。讲义称同一 Skill 格式可被 Claude Code、Codex、Cursor、Hermes 等客户端使用。

它特别强调安全边界：Skill 可以诱导 Agent 执行命令、访问文件和工具、下载远程内容，也可能出现隐藏指令、过度授权、工具投毒或“声明与实际行为不符”。讲义给出的 NVIDIA Verified Skills 流程是 **Cataloged → Scanned → Evaluated → Signed → Documented**，对应目录归属、SkillSpector 扫描、`BENCHMARK.md` 实测、`skill.oms.sig` 签名与 Skill Card 记录。讲义还区分能力层治理与运行时的 NeMo Guardrails、OpenShell、NemoClaw 等控制。[讲义预览](https://scrm.nvidia.cn/mF/cms/pdfPreview/aJ3K3GdqBdjdFXJFpCiGUZ/none/aJ3K3GdqBdjdFXJFpCiGUZ/RpAHERfoTpuBhhXhEnuWHS?pushId=RpAHERfoTpuBhhXhEnuWHS)，第 1–3 页。

**对参赛的实际含义（推断）：** Skill 的说明、脚本行为、权限范围和可复现评测应相互一致。讲义提出可信 Skill 的工程方法，但公开预览并未证明比赛要求每个作品完成 NVIDIA 官方签名或 Verified Skills 认证。

### 2. StepFun 多模态模型 × NVIDIA Agent Skills 的 Harness 演进实践

前 3 页把 Harness 定义为运行 Agent 的“壳”，包括 CLI、路由、技能加载等。讲义对比了两种交付方式：把工具用法塞进一次性长提示词，与把经验写成包含 `SKILL.md`、`references/`、`scripts/` 的目录。后者强调跨会话复用、校验和分发。讲义的核心主张是：多模态能力的交付，除模型 API 和应用胶水代码外，还应有**可验证的技能目录**。[讲义预览](https://scrm.nvidia.cn/mF/cms/pdfPreview/Vz6BPdujKk4CZ3E8BBe983/none/Vz6BPdujKk4CZ3E8BBe983/askELBFoTSnBEEw9iLwYnE?pushId=askELBFoTSnBEEw9iLwYnE)，第 1–3 页。

预览中“343 个技能”“50+ 客户端”等数量是讲义截至 2026-08 的陈述，本文不把它作为已独立验证的当前生态统计。后续具体模型调用方式、演示步骤和评测方法尚未见到完整材料。

### 3. NVIDIA DGX Spark 本地视觉 Agent 技能开发实战

前 3 页给出视觉 Agent 的整体位置：`Agent = LLM + Harness`，Harness 周围包含 Prompt、编排、工具与 Skills、安全治理、记忆和上下文。NVIDIA 软件栈示意图列出 Nemotron、NeMo、Dynamo、NIM、TensorRT-LLM、OpenShell 等组件，并把 CLI/MCP、文件、结构化与非结构化输入、多模态提示纳入 Agent 平台。[讲义预览](https://scrm.nvidia.cn/mF/cms/pdfPreview/jmHCRnDtoqb6FvrQwzyiGV/none/jmHCRnDtoqb6FvrQwzyiGV/hTHXMza9cooqxfjYuFhsdm?pushId=hTHXMza9cooqxfjYuFhsdm)，第 1–3 页。

这 3 页仍是架构导入，**没有展示完整视觉 Skill 的代码、模型文件、运行命令或验收结果**。图中出现的软件栈名称也不能自动写成基础 Workshop 全部实际使用。
