# WorldGen 生态调研与 WorldStage 参赛切入

**核对日期：2026-09-29。** 本文的 WorldGen 专指影眸 Hyper3D 的产品；Meta Reality Labs 也有一篇同名 WorldGen 论文，两者不能混为一谈。比赛主线以现有 [`WorldStage Physical Twin`](./完整方案.md) 为准。以下把厂商公开陈述、公开代码和本作品实测结果分别标注。

## 决策

**选择“生成场景的机器人任务准入与证据层”作为参赛融入点。** 影眸 WorldGen、World Labs Marble、腾讯 HY-World 和 NVIDIA Lyra/SAGE 都在扩展场景供给；NVIDIA SimReady Foundation 已在定义 USD 资产结构校验。WorldStage 应让一个场景回答更窄、更难的 S10 问题：尺寸和接触几何是否可信、哪些物理参数只是猜测、能否复现同一任务、跨引擎结果差在哪里、哪些结论有真实机器人证据。由 NVIDIA Nemotron 规划任务和变体，由 `scene-readiness-gate` 为场景做第一道结构准入，MuJoCo/Isaac/真实数据逐级补证。**这是一条作品定位与实施建议，不是已经证明的市场优势。**

WorldGen **不是当前核心运行依赖**。公开 [API 文档](https://docs.hyper3d.ai/en)写的是 Rodin 单资产图生/文生 3D，未见 WorldGen 场景 API；本作品已经通过登录后的网页工作台生成并导出两套真实 WorldGen 场景，写了专用离线适配器和来源回执。不能把 WorldStage 的程序化场景冒称 WorldGen 生成。[影眸官方新闻稿](https://www.prnewswire.com/news-releases/hyper3d-launches-worldgen-to-turn-single-images-into-editable-3d-scenes-302873750.html)；[Rodin API 文档](https://docs.hyper3d.ai/en)。

### 账号与费用实测（2026-09-29）

- 用户已登录并拥有 **Creator** 订阅；本次直接使用 Chrome 中的网页工作台，无须重新注册、邮箱验证、导入 API key 或追加付款。账户余额由 45 credits 变为 41 credits。网页生成使用了现有额度。
- [自动七物件工作区](https://hyper3d.ai/workspace/rodin/worldgen/f33f3e2a-4a84-4477-aed4-41942da80dff)导出 7 件独立 PBR GLB、变换矩阵和相机矩阵；[手动两物件与 3DGS 工作区](https://hyper3d.ai/workspace/rodin/worldgen/4b60933d-f55d-41fb-87d3-a155b3efba61)导出 2 件 GLB、`500k.spz` 和 `environment_collider.glb`。两份原 ZIP、逐件 SHA 和导入回执见 [`worldgen-assets/README.md`](../worldgen-assets/README.md)。
- **Complete Scene** 预设在该账户界面仍呈禁用态；通过手动选择物件后运行 FastGen，已得到 3DGS 背景。这只能证明该手动路径可用，不能推断全部预设和 API 的权限。
- [官方 API 文档](https://docs.hyper3d.ai/en/get-started/quick-start)要求 API key，且[公开 API 能力页](https://hyper3d.ai/features/api)列的是 Rodin 单资产功能；**没有证据证明 Business key 能调用 WorldGen 场景生成**。网页工作台生成不需要在本地项目导入 key。

## 从文章拆出可核实的技术命题

起点[量子位文章](https://www.qbitai.com/2026/09/483189.html)描述“单图 → 独立 3D 对象 → 对齐场景 → 碰撞/质量/摩擦”，并把机器人、游戏、影视与 XR 作为用途。影眸自己发布的[新闻稿](https://www.prnewswire.com/news-releases/hyper3d-launches-worldgen-to-turn-single-images-into-editable-3d-scenes-302873750.html)也明确说：可选择图片内对象；前景是 Rodin 生成的独立 mesh，背景是 3D Gaussian Splatting；估计对象尺度、姿态、接触/支撑关系、碰撞几何与质量/摩擦。底层 [CAST 论文](https://arxiv.org/abs/2502.12894)给出对象分割、遮挡补全、对齐和物理约束优化的方法。

这证明产品方向与技术来源，**没有独立证明**任意图片能准确恢复米制尺度、隐蔽几何、摩擦和质量，也没有证明把生成场景导入 Isaac Sim 就自动得到可用的机器人训练标签。单张 RGB 图没有这些物理量的真值；仿真属性必须校准或标成估计。报道中的“2–3 分钟”和合作/生产案例是厂商或采访口径，不能当本作品实测延迟或效果。

### 社区具体怎么玩

1. **创作与混搭**：从提示词/照片生成空间，挑出单个物件继续在 Blender/Unity 编辑；影视把 3D 场景作为分镜与运镜底板，再送给视频模型。来自影眸[官方用例](https://www.prnewswire.com/news-releases/hyper3d-launches-worldgen-to-turn-single-images-into-editable-3d-scenes-302873750.html)。
2. **可走进的内容**：Marble 的 [World API](https://www.worldlabs.ai/blog/announcing-the-world-api)列出视频变空间、游戏/社交体验、建筑客户导览；Meta 的 [Horizon 创作者案例](https://developers.meta.com/horizon/blog/worlds/unlocking-creativity-with-genai-worlds-creators-building-faster-smarter/)展示 mesh、skybox 和创作者工作流。这说明玩法正在从“看生成图”转向“编辑、分享和进入空间”，但没有给出通用物理准确性。
3. **机器人 digital cousins**：实拍拆物后系统性变化布局、外观、物理参数和任务。SimFoundry 的[公开仓库](https://github.com/NVlabs/SimFoundry)已将此作为独立管线；我们可把“危险/稀缺地形反例”作为 S10 具体任务，不必复制其通用室内生成系统。
4. **开源复现与插件**：腾讯发布代码权重，NVIDIA 发布场景生成和 SimReady 框架，Hyper3D [文档](https://docs.hyper3d.ai/en)链接 Discord 支持 Rodin API 交流。这些是可见社区入口；本次未核验活跃用户规模、商业留存或各家实际转化。

## 与现有黑客松作品的衔接

当前赛事是第三届 DGX Spark **Agent Skills 开发挑战赛**；本地[赛事核对](./第三届DGX-Spark黑客松_赛事与训练营摘要_2026-09-28.md)记录预赛提交窗口到 **09-29**，但精确截止时刻及私有评分规则未核实。现有 WorldStage 已具 80×80 m 世界、真实 S10 URDF、Rapier 预览、MJCF 导出与 MuJoCo 冒烟测试；[GX10 Nemotron 4B 回执](../results/worldstage/gx10-nemotron-receipt.json)证明特定实例上模型调用与物体生成。Isaac Sim 同场景、S10 动力控制和真实机器人均未运行。

```
照片/提示词/外部生成场景
  → world-intake：记录来源、许可、图像 SHA、尺度证据
  → WorldGen/Marble/HY-World/程序化资产：得到对象和视觉背景
  → scene-readiness-gate：结构、碰撞代理、参数来源、MJCF 可导出性
  → Nemotron：把 S10 任务转成场景变体/验收问题
  → MuJoCo 与 Isaac Sim：同坐标/初态/seed 的真实编译和步进
  → real2sim-calibrate：仅用授权真机数据更新参数，形成 World Episode
```

**这次已落地的切片**：新增 [`scene-readiness-gate`](../demo-3d/skills/scene-readiness-gate/SKILL.md) 与 [`scene_gate.py`](../demo-3d/studio/scene_gate.py)，并打入交付包。`/lab.html` 右侧可复核当前动态场景并下载报告。它检查 schema、单位、物体 ID/尺度/质量/摩擦、MJCF 导出；当前样例结构 `PASS`，同时指出斜坡在 MJCF 中是 box 碰撞代理、物理参数未测、来源图/资产回执缺失。输出的机器人训练和 NVIDIA SimReady 状态仍为 `NOT_RUN`。参见[`scene_gate.json`](../demo-3d/examples/physical-world/scene_gate.json)。

**接 WorldGen 的最小合同与本次执行**：逐件记录 `id`、mesh/碰撞资产 SHA、pose/scale、质量/摩擦的来源和测量状态；把 3DGS 仅作视觉背景，另给地面和接触物体明确碰撞几何；保存输入图像 SHA、工作区和原 ZIP。七件真实导出的 GLB 经 [`import_worldgen.py`](../demo-3d/studio/import_worldgen.py) 映射为 `worldstage.physical.v1` 的**估计包围盒**，附 `worldstage.scene_source.v1` 来源回执并送进 gate；七件导出资产的文件 SHA 均已核对，结构 `PASS`。原导出不提供已验证的米制尺度，导入器采用“1 GLB 单位 = 1 米”的待校准假设；斜坡/台阶接触、质量和摩擦均不能据此认定可供机器人训练。[运行记录](../worldgen-assets/README.md)和[准入结果](../worldgen-assets/auto-converted/scene_gate.json)可复核。

### 90 秒展示与下一步验收

| 阶段 | 展示材料 | 可说的结论 |
|---|---|---|
| 现在 | GX10 回执 → Nemotron 生成障碍 → S10 模型和世界 → 场景 gate 报告 → MJCF/MuJoCo 冒烟 | Skill 实际运行、生成对象可编入场景、已发现未测参数和碰撞代理风险 |
| 已完成的 WorldGen 切片 | 输入图像、两份 WorldGen 原 ZIP、逐件 SHA/变换、7 GLB 浏览器展示与 gate 报告 | 外部场景进入了 WorldStage 的审查流程；仍未证明训练可用 |
| 总决赛前 | 同场景 Isaac/MuJoCo 的配对接触/轨迹，真实 S10 小样本和校准前后对照 | 仅按各层实测结果逐级提升结论；至少包含失败案例和反例 |

衡量指标优先用：每场景人工修正时间、对象 ID/来源覆盖率、尺度与碰撞复核通过率、可复现编译/步进率、同场景跨引擎接触时刻/位姿差、固定任务的失败发现率。真机指标须有原始反馈和操作者观察，浏览器代理或单箱体自由落体不能替代。

## 决策边界

- **不做一个新的 WorldGen 基础模型。** 上游模型和开放社区进展很快；短期拼画质会稀释现有 Nemotron + S10 + 物理世界的比赛故事。
- **不把“SimReady”当营销形容词。** 影眸的 SimReady 是其厂商产品模式；NVIDIA SimReady Foundation 是具体 OpenUSD 规范。WorldStage 当前仅有自定义 JSON/MJCF 的结构 gate 和局部物理探针。
- **不虚构付费/开放能力。** 网页工作台和本次 4 credits 消耗已实测；WorldGen 场景 API 尚未公开确认。Rodin 单资产 API 已公开，不能据此推断 WorldGen 场景 API 可直接调用。导出使用范围按[官方价格页](https://hyper3d.ai/pricing)和[服务条款](https://hyper3d.ai/legal/terms)核对，并受素材第三方权利与比赛规则约束。
- **不把竞争对手写成空白。** SAGE/SimFoundry 已做场景生成与仿真编译；本方案要用 S10 任务和可追踪跨引擎/实物证据证明具体增量。
