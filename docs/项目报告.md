# WorldStage Physical Twin 项目报告

## 项目摘要

机器人团队通常能在仿真器里运行一个场景，却很难持续得到可追溯的新场景：一个台阶从哪里来，质量和摩擦是否实测，浏览器里看到的运动能否拿去训练，往往混在一起。WorldStage 把“提出场景—生成物体—探索—导出—复核”做成可重复执行的 Skill 流程，让每个结果带着来源和验收边界离开页面。

本次提交的是可运行的垂直切片。用户在 80 × 80 米的三维场景中输入“增加一块低矮的石台阶”，物体会获得几何、材质、质量和摩擦属性，加入 Rapier 物理世界。场景里的 DEEPRobotics S10 来自真实 URDF；用户可让运动学代理探索、记录位置和接触，再导出 JSON、MuJoCo XML、轨迹与场景准入报告。另有创意世界入口，六项 Skill 把主题写成可交互的微型 3D 场景。

## Agent Skills 与模型

13 个独立 Skill 分别负责主题理解、世界规划、3D 构建、交互与叙事、导出核验、物理世界编排、URDF 导入、探索采集、场景准入及 Nemotron 服务审计。它们有明确输入输出与可读文件，相关实现位于 `demo-3d/skills/` 和 `demo-3d/studio/`。

核心自然语言物体生成使用 NVIDIA Nemotron。在租用的 ASUS Ascent GX10（NVIDIA GB10）上，本项目运行 NVIDIA 官方 `NVIDIA-Nemotron-3-Nano-4B-GGUF` 权重与 llama.cpp CUDA 后端；`/v1/models` 返回 `nemotron-3-nano-4b-gguf`，WorldStage 生成了斜坡、台阶等物体。模型仓库修订号、权重 SHA、进程命令、响应和模型字段接纳情况保存在 [`gx10-nemotron-receipt.json`](../results/worldstage/gx10-nemotron-receipt.json)。这是本次实测的 4B GGUF 模型，不能写成 Omni 已部署。当前本地服务若未连接模型，页面显示模板回退，生成记录也标注 `template`。

## 技术实现与复核

前端由 Three.js、Rapier 和 Vite 构成；Python 服务承担 Skill 编排、模型 API 请求、结果落盘与导出。S10 原始 URDF 的 SHA-256 为 `64903c21f925583b99d69220aef8214ec458498c23eacb7b83e8e48afd70f3e8`，解析出 20 连杆、19 关节、27 个碰撞体。网页显示的是基于其碰撞结构的代理，运动方式是运动学控制。

MuJoCo 3.14.0 已编译 S10 与世界组合场景，并完成 1.2 秒无控制步进；另保存了 60 帧关节状态及接触数。Rapier/MuJoCo 配对只覆盖单个 2 kg 自由落体探针，接触前平均高度差 0.00772 米。这些结果是物理管线的冒烟测试，不能推导出 S10 的跨引擎动力学一致。

场景准入 Skill 检查结构与 MJCF 可导出性，并明确列出未测物理参数和碰撞代理差异。复核命令：

```bash
cd demo-3d
python3 studio/verify_delivery.py
python3 studio/server.py
```

本次交付验证为 `PASS: build, 13 skills, S10 source SHA, scene gate, physical world assets, 3 themes, negative contract, artifact hashes`。启动后访问 `http://127.0.0.1:8765/lab.html`，依次生成物体、复核场景、下载报告及 MuJoCo XML。完整验收项目见[验收状态](验收状态.md)，GX10 部署检查见[`final-deployment-check.json`](../results/worldstage/final-deployment-check.json)。

## 当前结论与下一步

已完成：本地场景生成与交互、13 个 Skill、S10 URDF 结构导入、Rapier 物理预览、MuJoCo 场景导出和冒烟测试、单刚体配对，以及 GX10 上 Nemotron 4B 的真实推理。未运行：Nemotron Omni、Isaac Sim 同场景、S10 关节级控制、真实机器人采集及 sim2real 收益评测。

下一步是在相同初态下比较 Rapier、MuJoCo 与 Isaac Sim 的接触相位和物体轨迹，再用授权的机器人数据校准质量、摩擦和碰撞体。只有跨引擎误差收敛、真实反馈可复核后，场景才适合作为训练或评测材料。当前生成物的物理参数应视为待测假设。
