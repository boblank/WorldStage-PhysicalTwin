# 《我的机器人分身》｜WorldStage Physical Twin 项目报告

## 项目价值

用户穿越为机器人分身，在一间失忆的试验仓中探索和解谜；开发者得到带来源、动作意图、碰撞事件和验收边界的仿真场景候选。作品将创作体验与机器人场景筛选连接起来，但不会把网页代理运动称为机器人训练数据。

## 可运行体验

进入 `/lab.html` 后选择 DEEPRobotics S10 或 ROBOTIS TurtleBot3 Burger 分身。玩家沿信号打开记忆宝箱，生成斜坡安抚守门兽，绕到黄栏后找到隐藏见证者，回答尺度问题，再运行场景准入门，最后选择实验室、现实残影或数字分身三条真相。宝箱、小怪兽和 NPC 均是三维世界中的近距离互动对象；移动方向、代理位置、碰撞、谜题选择与生成来源进入轨迹 JSON。

中心试验区加载经授权 Hyper3D WorldGen 实际导出的七件 PBR GLB，保留原图、原导出 ZIP、逐件 SHA 和变换矩阵。浏览器由七件源网格创建七个 Rapier 静态三角网格碰撞体，共 123308 个三角面。围合试验仓的墙体、灯光、地板、标识和谜题物件是本项目另行编制的视觉层，不能称为 WorldGen 原生输出。

## NVIDIA 模型与 Skill 组合

租用的 ASUS Ascent GX10 上实际运行 NVIDIA 官方 Nemotron 3 Nano 4B GGUF 和 llama.cpp CUDA 后端。WorldStage 已通过模型服务生成台阶、斜坡等结构化新物体；响应保存模型 ID、字段接纳、回退原因和耗时。本次使用的不是 Nemotron Omni。GX10 回执见 [`gx10-nemotron-receipt.json`](../results/worldstage/gx10-nemotron-receipt.json)。本地未连接模型时，页面显式标为模板模式。

作品打包 16 个 Skill，覆盖世界规划、构建、叙事、交互、导出与核验，以及 URDF 导入、WorldGen 来源接入、场景准入、探索记录和 Nemotron 服务审计。对应实现位于 `demo-3d/skills/` 和 `demo-3d/studio/`。

## 仿真证据与边界

S10 原始 URDF SHA-256 为 `64903c21f925583b99d69220aef8214ec458498c23eacb7b83e8e48afd70f3e8`；TurtleBot3 Burger 保留官方 URDF 与 Apache-2.0 许可证。MuJoCo 已编译 S10 与场景并无控制步进 1.2 秒，保存 60 帧关节状态和接触数。Rapier/MuJoCo 只对一个 2 kg 自由落体箱做了配对探针，接触前平均高度差 0.00772 米。

WorldGen 的米制尺度、摩擦和真实接触行为没有实测。浏览器约定一源网格单位等于一演示米；MJCF 导出仍使用简化形状。场景准入将七项跨引擎碰撞形状差异列出，并将机器人训练标为 `BLOCKED`。网页分身为运动学代理；Isaac Sim 同场景、S10 关节级控制、真实机器人采集、图片生成可驱动 URDF 和 Sim2Real 收益均未运行。

## 复核与交付

```bash
cd demo-3d
npm ci
npm run build
python3 studio/verify_delivery.py
python3 studio/server.py
```

访问 `http://127.0.0.1:8765/lab.html`。`release/worldstage-3h.zip` 内含预构建页面，可独立解压运行；其 SHA-256 见 `release/SHA256SUMS.txt`。验收项见[验收状态](验收状态.md)，WorldGen 原件与来源见[资产清单](../worldgen-assets/README.md)。
